JAWA — NOUVELLE PAGE D'ACCUEIL

1. Sauvegardez votre projet actuel avant de modifier les fichiers.
2. Dans VS Code, ouvrez le dossier de votre site existant.
3. Copiez votre ancien index.html et ses fichiers associés dans un sous-dossier menu/.
   IMPORTANT : vérifiez et corrigez les chemins des images, CSS et JS dans menu/index.html.
4. Placez index.html, style.css, script.js et le dossier images/ de cette archive à la racine du projet.
5. Remplacez les liens # (Facebook, TikTok, Google Maps) dans index.html par vos vraies URL.
6. Testez la page d'accueil ET le menu avec Live Server avant toute publication.
7. Publiez : git add . && git commit -m "Add JAWA landing page" && git push origin main

NOTE : L'image hero-jawa.webp est un recadrage de la maquette fournie : elle contient le logo dessiné dans l'image, pas un logo HTML séparé. Pour une qualité optimale, remplacez-la ultérieurement par votre photo originale et le vrai logo transparent.
NOTE : Le lien menu/ ne fonctionnera qu'après déplacement et test du menu existant.
